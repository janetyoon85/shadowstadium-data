ShadeSide プライバシーポリシー

施行日: 2026年6月1日
最終改訂日: 2026-10-10
バージョン: 1.1

本プライバシーポリシーは、モバイルアプリケーション「ShadeSide」（以下「本アプリ」）の利用に関連する情報の収集・利用・保護について説明するものです。本アプリの開発者はユーザーのプライバシーを尊重し、関連法令を遵守します。

1. 直接収集する個人情報

本アプリはユーザーの個人情報を直接収集しません。

  • 会員登録機能なし
  • 氏名、電話番号、メールアドレスなどの識別情報の入力を求めません
  • 端末の位置情報（GPS）へのアクセス権限を要求しません
  • カメラ、マイク、連絡先などの機密性の高い権限は要求しません
  • 写真ライブラリへのアクセスは、ユーザーが試合画像の保存・共有を選んだときにのみ、その画像を保存する目的でのみ要求します

2. 端末内に保存される情報

本アプリは利便性のため、次の情報をユーザーの端末内にのみ保存します。この情報は外部サーバーに送信されず、アプリ削除時に一緒に削除されます。

保存項目用途
お気に入り球場リストホーム画面での優先表示
お気に入りチームリスト自チームの試合の自動通知
通知タイミング設定（1/3/6/12/24時間）ユーザー通知環境設定
通知ON/OFF状態試合ごとの通知管理
試合日程キャッシュオフライン利用のサポート

3. 第三者サービスの利用

本アプリは以下の第三者サービスを利用しており、当該サービスが自ら一部の情報を収集する場合があります。

3.1 Google AdMob（広告）

本アプリはバナー広告表示のためにGoogle AdMobを使用します。AdMobは次の情報を自動的に収集することがあります：

  • 広告識別子（Android Advertising ID / iOS IDFA）
  • 端末情報（機種名、OSバージョン、画面サイズ、言語設定）
  • IPアドレスおよびおおよその位置（国・地域レベル）
  • 広告表示およびインタラクションの記録

iOSでは、本アプリはパーソナライズされていない広告のみをリクエストし、App Tracking Transparency（ATT）のポップアップは表示しません。広告識別子（IDFA）を追跡目的で使用することもありません。

ユーザーは端末設定から広告識別子をリセットしたり、パーソナライズ広告をオプトアウトしたりできます。

詳細：Googleプライバシーポリシー

3.2 外部API呼び出し（球場位置情報のみ送信）

本アプリは試合日程および天気情報を取得するために以下のAPIを呼び出しますが、ユーザーの個人情報は送信しません。

サービス送信情報用途
Naver Sports APIなし（公開日程のみ照会）KBO・Kリーグの試合日程
Open-Meteo球場の緯度経度座標（ユーザーの位置情報ではありません）球場別の天気予報

上記API呼び出し時、端末のIPアドレスが該当サーバーに送信される場合がありますが、識別可能な個人情報は送信されません。

3.3 Firebase Cloud Messaging（プッシュ通知）

本アプリはプッシュ通知の配信にGoogle Firebase Cloud Messaging（FCM）を使用します（iOSではAppleプッシュ通知サービス経由）。通知配信のため、FCMは端末にプッシュトークンとインストール識別子を割り当てます。また、ユーザーが選んだチーム・試合・選手・言語に対応する通知トピック（例：お気に入りチームの試合終了通知）を端末に登録します。本アプリにはアカウントがないため、これらのトピックは氏名やメールアドレスなどユーザーの身元とは結び付けられません。通知は端末設定でオフにでき、アプリでお気に入りを解除すると該当トピックの登録が解除されます。 詳細：Firebaseのプライバシーとセキュリティ

3.4 Sentry（クラッシュ・パフォーマンス報告）

本アプリは問題を修正するために、Sentryでクラッシュレポートと基本的なパフォーマンス測定値を受け取ります。レポートにはエラー内容とスタックトレース、端末モデル、OSバージョン、アプリバージョンなどの技術情報が含まれます。氏名、メールアドレス、アカウント識別子などの個人情報は送信しないよう設定されています。 詳細：Sentryプライバシーポリシー

3.5 YouTube APIサービス

本アプリは、試合ハイライトおよび応援歌の動画をリンクするためにYouTube APIサービス（YouTube Data API）を使用します。呼び出しは当社サーバーからのみ行われ、アプリ利用者の個人情報やGoogleアカウント情報がYouTubeに送信・収集されることはありません。保存するのは動画IDとタイトルのみです。動画を開くとYouTube（アプリまたはブラウザ）に移動し、YouTube利用規約およびGoogleプライバシーポリシーが適用されます。当社はYouTubeユーザーデータを保存しないため、削除対象のデータはありません。Googleアカウントに付与した権限はGoogleのセキュリティ設定で取り消せます。

4. 通知（Notifications）

本アプリはユーザーが選んだチーム・試合・選手に関する通知を送信します。通知はFirebase Cloud Messaging（3.3参照）によるプッシュ通知として配信されるため、そのために端末のプッシュトークンがGoogleおよびAppleで処理されます。個人情報の入力は必要ありません。通知設定はユーザーがいつでも変更・解除できます。

5. 権限使用について

権限用途
通知の送信（POST_NOTIFICATIONS）試合開始前の通知
正確なアラーム（USE_EXACT_ALARM）通知時刻の正確性を保証
インターネット（INTERNET, ACCESS_NETWORK_STATE）試合日程・天気の取得、広告表示
広告ID（AD_ID）パーソナライズ広告（ユーザーはオプトアウト可能）
写真ライブラリ（保存のみ）ユーザーが共有のために選んだ試合画像の保存

6. 児童のプライバシー保護

本アプリは13歳未満の児童を対象としておらず、13歳未満のユーザーから意図的に個人情報を収集することはありません。

7. ユーザーの権利

ユーザーは以下の権利を行使できます：

  • アプリの削除により端末内に保存されたすべての情報を即座に削除
  • 端末設定から通知権限を変更
  • 端末設定から広告識別子をリセットまたはパーソナライズ広告を拒否

8. ポリシーの変更

本プライバシーポリシーは法令またはサービスの変更に応じて改訂される場合があり、変更時は本ページに掲載します。重大な変更がある場合は、アプリ内通知またはアップデートノートを通じてお知らせします。
