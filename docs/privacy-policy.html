그늘각 (ShadowStadium) 개인정보처리방침

시행일: 2026년 6월 1일
최종 수정일: 2026년 6월 1일
버전: 1.0

본 개인정보처리방침은 모바일 애플리케이션 "그늘각(ShadowStadium)" (이하 "앱")의 이용에 관련된 정보 수집·이용·보호에 관한 사항을 알려드립니다. 본 앱의 개발자는 사용자의 개인정보를 소중히 여기며, 관련 법령을 준수합니다.

1. 직접 수집하는 개인정보

본 앱은 사용자의 개인정보를 직접 수집하지 않습니다.

  • 회원가입 기능 없음
  • 이름, 연락처, 이메일 등 식별정보 입력 요청 없음
  • 사용자의 디바이스 위치(GPS) 접근 권한을 요청하지 않습니다
  • 카메라, 마이크, 연락처, 저장소 등 민감 권한을 요청하지 않습니다

2. 디바이스 내부에 저장되는 정보

본 앱은 사용자의 편의를 위해 다음 정보를 사용자 디바이스 내부에만 저장합니다. 이 정보는 외부 서버로 전송되지 않으며, 앱 삭제 시 함께 삭제됩니다.

저장 항목용도
즐겨찾는 구장 목록홈 화면 우선 표시
즐겨찾는 팀 목록내 팀 경기 자동 알림
알림 시점 설정 (1/3/6/12/24시간)사용자 알림 환경설정
알림 ON/OFF 상태경기별 알림 관리
경기 일정 캐시오프라인 사용 지원

3. 제3자 서비스 이용

본 앱은 다음 제3자 서비스를 이용하며, 해당 서비스가 자체적으로 일부 정보를 수집할 수 있습니다.

3.1 Google AdMob (광고)

본 앱은 배너 광고 표시를 위해 Google AdMob을 사용합니다. AdMob은 다음 정보를 자동으로 수집할 수 있습니다:

  • 광고 식별자 (Android Advertising ID / iOS IDFA)
  • 디바이스 정보 (모델명, OS 버전, 화면 크기, 언어 설정)
  • IP 주소 및 대략적인 위치 (국가/지역 수준)
  • 광고 노출 및 상호작용 기록

사용자는 디바이스 설정에서 광고 식별자를 재설정하거나 맞춤 광고를 옵트아웃할 수 있습니다.

자세한 내용: Google 개인정보처리방침

3.2 외부 API 호출 (구장 위치만 전송)

본 앱은 경기 일정 및 날씨 정보를 가져오기 위해 다음 API를 호출하며, 사용자 개인정보는 전송하지 않습니다:

서비스전송 정보용도
Naver Sports API 없음 (공개 일정만 조회) KBO·K리그 경기 일정
Open-Meteo 구장 위경도 좌표 (사용자 위치 아님) 구장별 날씨 예보

위 API 호출 시 사용자 디바이스의 IP 주소는 해당 서버에 전달될 수 있으나, 식별 가능한 개인정보는 전송하지 않습니다.

4. 알림 (Notifications)

본 앱은 사용자가 설정한 경기 시각 알림을 발송합니다. 모든 알림은 디바이스 내부에서 로컬로 처리되며, 외부 서버로부터 푸시 알림을 받지 않습니다. 알림 설정은 사용자가 언제든 변경하거나 해제할 수 있습니다.

6. 아동 개인정보 보호

본 앱은 만 13세 미만의 아동을 대상으로 하지 않으며, 만 13세 미만 사용자로부터 의도적으로 개인정보를 수집하지 않습니다.

7. 사용자 권리

사용자는 다음 권리를 행사할 수 있습니다:

  • 앱 삭제를 통해 디바이스 내 저장된 모든 정보를 즉시 삭제
  • 디바이스 설정에서 알림 권한 변경
  • 디바이스 설정에서 광고 식별자 재설정 또는 맞춤 광고 거부

8. 정책 변경

본 개인정보처리방침은 법령 또는 서비스 변경에 따라 수정될 수 있으며, 변경 시 본 페이지에 게시합니다. 중대한 변경 사항이 있을 경우 앱 내 공지 또는 업데이트 노트를 통해 안내드립니다.
