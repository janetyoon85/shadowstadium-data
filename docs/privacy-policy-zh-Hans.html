ShadeSide隐私政策

生效日期：2026年6月1日
最后修订日期：2026-10-10
版本：1.1

本隐私政策说明了移动应用程序"ShadeSide"（以下简称"本应用"）在您使用本应用过程中如何收集、使用和保护相关信息。本应用的开发者重视您的隐私，并遵守相关法律法规。

1. 我们直接收集的个人信息

本应用不直接收集用户的任何个人信息。

  • 无注册或创建账户功能
  • 不要求输入姓名、电话、电子邮件等身份识别信息
  • 不请求访问设备的位置信息（GPS）
  • 不会请求相机、麦克风、通讯录等敏感权限
  • 仅当您选择保存或分享比赛图片时才会请求相册访问权限，且仅用于保存该图片

2. 存储在您设备中的信息

为方便您使用，本应用会将以下信息仅存储在您的设备中。这些信息不会发送到外部服务器，并会在卸载应用时一并删除。

存储项目用途
收藏球场列表在主页优先显示
收藏球队列表自动提醒您球队的比赛
提醒时间设置（1/3/6/12/24小时）用户通知偏好设置
提醒开关状态按比赛管理提醒
比赛日程缓存支持离线使用

3. 第三方服务的使用

本应用使用以下第三方服务，这些服务可能会自行收集某些信息。

3.1 Google AdMob（广告）

本应用使用Google AdMob展示横幅广告。AdMob可能会自动收集以下信息：

  • 广告标识符（Android Advertising ID / iOS IDFA）
  • 设备信息（型号、操作系统版本、屏幕尺寸、语言设置）
  • IP地址及大致位置（国家/地区级别）
  • 广告展示及互动记录

在 iOS 上，本应用仅请求非个性化广告，不会显示应用跟踪透明度（ATT）弹窗，也不会将广告标识符（IDFA）用于跟踪。

您可以在设备设置中重置广告标识符或选择退出个性化广告。

详情请参阅：Google隐私政策

3.2 外部API调用（仅发送球场位置信息）

本应用调用以下API获取比赛日程和天气信息，不会发送用户的个人信息。

服务发送的数据用途
Naver Sports API无（仅查询公开日程）KBO/K联赛比赛日程
Open-Meteo球场经纬度坐标（非用户位置）各球场天气预报

调用上述API时，设备的IP地址可能会被传输至相应服务器，但不会发送可识别的个人信息。

3.3 Firebase Cloud Messaging（推送通知）

本应用使用 Google Firebase Cloud Messaging（FCM）发送推送通知（iOS 上通过 Apple 推送通知服务）。为发送通知，FCM 会为您的设备分配推送令牌和安装标识符。应用还会让您的设备订阅与您所选球队、比赛、球员和语言对应的通知主题（例如关注球队的比赛结束提醒）。由于本应用没有账户，这些主题不会与您的姓名、电子邮件或任何账户关联。您可以在设备设置中关闭通知，或在应用中取消收藏以取消订阅相应主题。 详细信息：Firebase 隐私与安全

3.4 Sentry（崩溃与性能报告）

本应用使用 Sentry 接收崩溃报告和基本性能测量数据，以便修复问题。报告包含错误和堆栈跟踪、设备型号、操作系统版本、应用版本等技术信息。应用已设置为不发送姓名、电子邮件、账户标识符等个人信息。 详细信息：Sentry 隐私政策

3.5 YouTube API 服务

本应用使用 YouTube API 服务（YouTube Data API）来链接比赛集锦和加油歌曲视频。调用仅由我们的服务器发出；不会向 YouTube 发送或从中收集应用用户的个人信息或 Google 账号信息。我们仅存储视频 ID 和标题。打开视频时会跳转到 YouTube（应用或浏览器），适用 YouTube 服务条款 和 Google 隐私权政策。我们不存储 YouTube 用户数据，因此没有需要删除的数据。您可以在 Google 安全设置 中撤销授予 Google 账号的权限。

4. 通知

本应用会发送您所选球队、比赛和球员的提醒。通知通过 Firebase Cloud Messaging（见 3.3）以推送通知方式送达，因此您设备的推送令牌会由 Google 和 Apple 为此处理。无需提供任何个人信息。您可以随时更改或关闭通知设置。

5. 权限使用说明

权限用途
发送通知（POST_NOTIFICATIONS）比赛开始前提醒
精确闹钟（USE_EXACT_ALARM）保证提醒时间的准确性
网络（INTERNET, ACCESS_NETWORK_STATE）获取比赛日程/天气，显示广告
广告ID（AD_ID）个性化广告（用户可选择退出）
相册（仅保存）保存您选择分享的比赛图片

6. 儿童隐私保护

本应用不面向13岁以下儿童，我们不会故意收集13岁以下用户的个人信息。

7. 您的权利

您可以行使以下权利：

  • 通过卸载应用立即删除设备中存储的所有信息
  • 在设备设置中更改通知权限
  • 在设备设置中重置广告标识符或拒绝个性化广告

8. 本政策的变更

本隐私政策可能因法律或服务变更而修订，任何变更将发布在本页面。如有重大变更，我们将通过应用内通知或更新说明告知您。
