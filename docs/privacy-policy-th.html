นโยบายความเป็นส่วนตัวของมุมเงา (ShadowStadium)

วันที่มีผลบังคับใช้: 1 มิถุนายน 2026
แก้ไขล่าสุด: 1 มิถุนายน 2026
เวอร์ชัน: 1.0

นโยบายความเป็นส่วนตัวนี้อธิบายว่าแอปพลิเคชันมือถือ "มุมเงา (ShadowStadium)" ("แอป") เก็บรวบรวม ใช้ และปกป้องข้อมูลที่เกี่ยวข้องกับการใช้แอปของคุณอย่างไร ผู้พัฒนาแอปนี้ให้ความสำคัญกับความเป็นส่วนตัวของคุณและปฏิบัติตามกฎหมายที่เกี่ยวข้อง

1. ข้อมูลส่วนบุคคลที่เราเก็บรวบรวมโดยตรง

แอปนี้ ไม่เก็บรวบรวมข้อมูลส่วนบุคคลของผู้ใช้โดยตรง

  • ไม่มีฟีเจอร์สมัครสมาชิกหรือสร้างบัญชี
  • ไม่ขอข้อมูลระบุตัวตน เช่น ชื่อ เบอร์โทร หรืออีเมล
  • ไม่ขอสิทธิ์เข้าถึงตำแหน่งที่ตั้ง (GPS) ของอุปกรณ์
  • ไม่ขอสิทธิ์ที่ละเอียดอ่อน เช่น กล้อง ไมโครโฟน รายชื่อติดต่อ หรือพื้นที่จัดเก็บข้อมูล

2. ข้อมูลที่จัดเก็บบนอุปกรณ์ของคุณ

เพื่อความสะดวกของคุณ แอปนี้จะจัดเก็บข้อมูลต่อไปนี้ บนอุปกรณ์ของคุณเท่านั้น ข้อมูลนี้จะไม่ถูกส่งไปยังเซิร์ฟเวอร์ภายนอก และจะถูกลบเมื่อคุณถอนการติดตั้งแอป

รายการที่จัดเก็บวัตถุประสงค์
รายการสนามโปรดแสดงผลก่อนบนหน้าหลัก
รายการทีมโปรดแจ้งเตือนอัตโนมัติสำหรับการแข่งขันของทีมคุณ
การตั้งค่าเวลาแจ้งเตือน (1/3/6/12/24 ชั่วโมง)การตั้งค่าการแจ้งเตือนของผู้ใช้
สถานะเปิด/ปิดการแจ้งเตือนการจัดการแจ้งเตือนรายนัด
แคชตารางการแข่งขันรองรับการใช้งานแบบออฟไลน์

3. การใช้บริการของบุคคลที่สาม

แอปนี้ใช้บริการของบุคคลที่สามต่อไปนี้ ซึ่งอาจเก็บรวบรวมข้อมูลบางอย่างด้วยตนเอง

3.1 Google AdMob (โฆษณา)

แอปนี้ใช้ Google AdMob เพื่อแสดงโฆษณาแบนเนอร์ AdMob อาจเก็บรวบรวมข้อมูลต่อไปนี้โดยอัตโนมัติ:

  • ตัวระบุโฆษณา (Android Advertising ID / iOS IDFA)
  • ข้อมูลอุปกรณ์ (รุ่น เวอร์ชันระบบปฏิบัติการ ขนาดหน้าจอ การตั้งค่าภาษา)
  • ที่อยู่ IP และตำแหน่งโดยประมาณ (ระดับประเทศ/ภูมิภาค)
  • บันทึกการแสดงผลและการโต้ตอบกับโฆษณา

คุณสามารถรีเซ็ตตัวระบุโฆษณาหรือยกเลิกการรับโฆษณาที่ปรับให้เหมาะกับคุณได้ในการตั้งค่าอุปกรณ์

รายละเอียดเพิ่มเติม: นโยบายความเป็นส่วนตัวของ Google

3.2 การเรียก API ภายนอก (ส่งเฉพาะตำแหน่งสนามเท่านั้น)

แอปนี้เรียก API ต่อไปนี้เพื่อดึงตารางการแข่งขันและข้อมูลสภาพอากาศ โดยไม่มีการส่งข้อมูลส่วนบุคคลของผู้ใช้

บริการข้อมูลที่ส่งวัตถุประสงค์
Naver Sports APIไม่มี (เรียกดูเฉพาะตารางแข่งสาธารณะ)ตารางการแข่งขัน KBO/K League
Open-Meteoพิกัดของสนาม (ไม่ใช่ตำแหน่งของผู้ใช้)พยากรณ์อากาศรายสนาม

เมื่อเรียก API เหล่านี้ ที่อยู่ IP ของอุปกรณ์อาจถูกส่งไปยังเซิร์ฟเวอร์ที่เกี่ยวข้อง แต่จะไม่มีการส่งข้อมูลส่วนบุคคลที่ระบุตัวตนได้

4. การแจ้งเตือน

แอปนี้ส่งการแจ้งเตือนสำหรับเวลาการแข่งขันที่คุณตั้งค่าไว้ การแจ้งเตือนทั้งหมดประมวลผลในเครื่องบนอุปกรณ์ของคุณ และแอปนี้ไม่ได้รับการแจ้งเตือนแบบพุชจากเซิร์ฟเวอร์ภายนอก คุณสามารถเปลี่ยนหรือปิดการตั้งค่าการแจ้งเตือนได้ทุกเมื่อ

5. การใช้สิทธิ์การเข้าถึง

สิทธิ์การเข้าถึงวัตถุประสงค์
ส่งการแจ้งเตือน (POST_NOTIFICATIONS)แจ้งเตือนก่อนการแข่งขันเริ่ม
การปลุกที่แม่นยำ (USE_EXACT_ALARM)รับประกันความแม่นยำของเวลาแจ้งเตือน
อินเทอร์เน็ต (INTERNET, ACCESS_NETWORK_STATE)ดึงตารางแข่ง/สภาพอากาศ แสดงโฆษณา
รหัสโฆษณา (AD_ID)โฆษณาที่ปรับให้เหมาะกับคุณ (ผู้ใช้สามารถยกเลิกได้)

6. ความเป็นส่วนตัวของเด็ก

แอปนี้ไม่ได้มุ่งเป้าไปที่เด็กอายุต่ำกว่า 13 ปี และเราจะไม่เก็บรวบรวมข้อมูลส่วนบุคคลจากผู้ใช้ที่อายุต่ำกว่า 13 ปีโดยเจตนา

7. สิทธิของคุณ

คุณสามารถใช้สิทธิ์ต่อไปนี้ได้:

  • ลบข้อมูลทั้งหมดที่จัดเก็บบนอุปกรณ์ของคุณทันทีโดยการถอนการติดตั้งแอป
  • เปลี่ยนสิทธิ์การแจ้งเตือนในการตั้งค่าอุปกรณ์ของคุณ
  • รีเซ็ตตัวระบุโฆษณาหรือปฏิเสธโฆษณาที่ปรับให้เหมาะกับคุณในการตั้งค่าอุปกรณ์ของคุณ

8. การเปลี่ยนแปลงนโยบายนี้

นโยบายความเป็นส่วนตัวนี้อาจได้รับการแก้ไขเนื่องจากการเปลี่ยนแปลงทางกฎหมายหรือบริการ และการเปลี่ยนแปลงใด ๆ จะประกาศในหน้านี้ หากมีการเปลี่ยนแปลงที่สำคัญ เราจะแจ้งให้คุณทราบผ่านการแจ้งเตือนในแอปหรือบันทึกการอัปเดต

9. ติดต่อเรา

หากคุณมีคำถามเกี่ยวกับความเป็นส่วนตัว โปรดติดต่อเราด้านล่าง
