ShadeSide隱私政策

生效日期：2026年6月1日
最後修訂日期：2026-10-10
版本：1.1

本隱私政策說明了行動應用程式「ShadeSide」（以下簡稱「本應用」）在您使用本應用過程中如何收集、使用及保護相關資訊。本應用的開發者重視您的隱私，並遵守相關法律法規。

1. 我們直接收集的個人資訊

本應用不直接收集使用者的任何個人資訊。

  • 無註冊或建立帳戶功能
  • 不要求輸入姓名、電話、電子郵件等身分識別資訊
  • 不請求存取裝置的位置資訊（GPS）
  • 不會要求相機、麥克風、聯絡人等敏感權限
  • 僅當您選擇儲存或分享比賽圖片時才會要求相簿存取權限，且僅用於儲存該圖片

2. 儲存在您裝置中的資訊

為方便您使用，本應用會將以下資訊僅儲存在您的裝置中。這些資訊不會傳送到外部伺服器，並會在解除安裝應用時一併刪除。

儲存項目用途
收藏球場清單在首頁優先顯示
收藏球隊清單自動提醒您球隊的比賽
提醒時間設定（1/3/6/12/24小時）使用者通知偏好設定
提醒開關狀態依比賽管理提醒
比賽賽程快取支援離線使用

3. 第三方服務的使用

本應用使用以下第三方服務，這些服務可能會自行收集某些資訊。

3.1 Google AdMob（廣告）

本應用使用Google AdMob顯示橫幅廣告。AdMob可能會自動收集以下資訊：

  • 廣告識別碼（Android Advertising ID / iOS IDFA）
  • 裝置資訊（型號、作業系統版本、螢幕尺寸、語言設定）
  • IP位址及大致位置（國家/地區層級）
  • 廣告顯示及互動記錄

在 iOS 上，本應用程式僅請求非個人化廣告，不會顯示 App 追蹤透明度（ATT）彈窗，也不會將廣告識別碼（IDFA）用於追蹤。

您可以在裝置設定中重設廣告識別碼或選擇退出個人化廣告。

詳情請參閱：Google隱私政策

3.2 外部API呼叫（僅傳送球場位置資訊）

本應用呼叫以下API取得比賽賽程與天氣資訊，不會傳送使用者的個人資訊。

服務傳送的資料用途
Naver Sports API無（僅查詢公開賽程）KBO/K聯賽賽程
Open-Meteo球場經緯度座標（非使用者位置）各球場天氣預報

呼叫上述API時，裝置的IP位址可能會被傳輸至相應伺服器，但不會傳送可識別的個人資訊。

3.3 Firebase Cloud Messaging（推播通知）

本應用程式使用 Google Firebase Cloud Messaging（FCM）傳送推播通知（iOS 上透過 Apple 推播通知服務）。為傳送通知，FCM 會為您的裝置指派推播權杖和安裝識別碼。應用程式也會讓您的裝置訂閱與您所選球隊、比賽、球員和語言對應的通知主題（例如關注球隊的比賽結束提醒）。由於本應用程式沒有帳號，這些主題不會與您的姓名、電子郵件或任何帳號連結。您可以在裝置設定中關閉通知，或在應用程式中取消收藏以取消訂閱相應主題。 詳細資訊：Firebase 隱私權與安全性

3.4 Sentry（當機與效能回報）

本應用程式使用 Sentry 接收當機報告和基本效能量測資料，以便修正問題。報告包含錯誤與堆疊追蹤、裝置型號、作業系統版本、應用程式版本等技術資訊。應用程式已設定為不傳送姓名、電子郵件、帳號識別碼等個人資訊。 詳細資訊：Sentry 隱私權政策

3.5 YouTube API 服務

本應用程式使用 YouTube API 服務（YouTube Data API）連結比賽精華與加油歌曲影片。呼叫僅由我們的伺服器發出；不會向 YouTube 傳送或從中收集應用程式使用者的個人資訊或 Google 帳戶資訊。我們僅儲存影片 ID 與標題。開啟影片時會前往 YouTube（應用程式或瀏覽器），適用 YouTube 服務條款 與 Google 隱私權政策。我們不儲存 YouTube 使用者資料，因此沒有需要刪除的資料。您可在 Google 安全性設定 中撤銷授予 Google 帳戶的權限。

4. 通知

本應用程式會傳送您所選球隊、比賽和球員的提醒。通知透過 Firebase Cloud Messaging（見 3.3）以推播通知方式送達，因此您裝置的推播權杖會由 Google 和 Apple 為此處理。無需提供任何個人資訊。您可以隨時變更或關閉通知設定。

5. 權限使用說明

權限用途
傳送通知（POST_NOTIFICATIONS）比賽開始前提醒
精確鬧鐘（USE_EXACT_ALARM）確保提醒時間的準確性
網路（INTERNET, ACCESS_NETWORK_STATE）取得比賽賽程/天氣，顯示廣告
廣告ID（AD_ID）個人化廣告（使用者可選擇退出）
相簿（僅儲存）儲存您選擇分享的比賽圖片

6. 兒童隱私保護

本應用不針對13歲以下兒童，我們不會故意收集13歲以下使用者的個人資訊。

7. 您的權利

您可以行使以下權利：

  • 透過解除安裝應用立即刪除裝置中儲存的所有資訊
  • 在裝置設定中變更通知權限
  • 在裝置設定中重設廣告識別碼或拒絕個人化廣告

8. 本政策的變更

本隱私政策可能因法律或服務變更而修訂，任何變更將公佈在本頁面。如有重大變更，我們將透過應用內通知或更新說明告知您。
