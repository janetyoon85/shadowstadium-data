Kebijakan Privasi Sudut Bayangan (ShadowStadium)

Tanggal berlaku: 1 Juni 2026
Terakhir diperbarui: 1 Juni 2026
Versi: 1.0

Kebijakan Privasi ini menjelaskan bagaimana aplikasi seluler "Sudut Bayangan (ShadowStadium)" ("Aplikasi") mengumpulkan, menggunakan, dan melindungi informasi terkait penggunaan Aplikasi oleh Anda. Pengembang Aplikasi ini menghargai privasi Anda dan mematuhi hukum yang berlaku.

1. Informasi Pribadi yang Kami Kumpulkan Secara Langsung

Aplikasi ini tidak mengumpulkan informasi pribadi pengguna secara langsung.

  • Tidak ada fitur pendaftaran atau pembuatan akun
  • Tidak meminta informasi identitas seperti nama, telepon, atau email
  • Tidak meminta akses ke lokasi (GPS) perangkat Anda
  • Tidak meminta izin sensitif seperti kamera, mikrofon, kontak, atau penyimpanan

2. Informasi yang Disimpan di Perangkat Anda

Demi kenyamanan Anda, Aplikasi ini menyimpan informasi berikut hanya di perangkat Anda. Informasi ini tidak pernah dikirim ke server eksternal dan akan terhapus saat Aplikasi dihapus.

3. Penggunaan Layanan Pihak Ketiga

Aplikasi ini menggunakan layanan pihak ketiga berikut, yang mungkin mengumpulkan informasi tertentu secara mandiri.

3.1 Google AdMob (Iklan)

Aplikasi ini menggunakan Google AdMob untuk menampilkan iklan banner. AdMob dapat secara otomatis mengumpulkan informasi berikut:

  • Pengenal iklan (Android Advertising ID / iOS IDFA)
  • Informasi perangkat (model, versi OS, ukuran layar, pengaturan bahasa)
  • Alamat IP dan perkiraan lokasi (tingkat negara/wilayah)
  • Catatan tayangan dan interaksi iklan

Anda dapat mengatur ulang pengenal iklan atau menonaktifkan iklan yang dipersonalisasi di pengaturan perangkat Anda.

Selengkapnya: Kebijakan Privasi Google

3.2 Panggilan API Eksternal (Hanya Lokasi Stadion yang Dikirim)

Aplikasi ini memanggil API berikut untuk mendapatkan jadwal pertandingan dan informasi cuaca. Tidak ada informasi pribadi pengguna yang dikirim.

LayananData yang DikirimTujuan

Saat memanggil API ini, alamat IP perangkat dapat dikirim ke server terkait, tetapi tidak ada informasi pribadi yang dapat diidentifikasi yang dikirim.

4. Notifikasi

Aplikasi ini mengirimkan pengingat untuk waktu pertandingan yang Anda atur. Semua notifikasi diproses secara lokal di perangkat Anda, dan Aplikasi ini tidak menerima notifikasi push dari server eksternal. Anda dapat mengubah atau menonaktifkan pengaturan pengingat kapan saja.

6. Privasi Anak-anak

Aplikasi ini tidak ditujukan untuk anak-anak di bawah usia 13 tahun, dan kami tidak dengan sengaja mengumpulkan informasi pribadi dari pengguna di bawah usia 13 tahun.

7. Hak Anda

Anda dapat menggunakan hak-hak berikut:

  • Segera menghapus semua informasi yang tersimpan di perangkat Anda dengan menghapus Aplikasi
  • Mengubah izin notifikasi di pengaturan perangkat Anda
  • Mengatur ulang pengenal iklan atau menolak iklan yang dipersonalisasi di pengaturan perangkat Anda

8. Perubahan pada Kebijakan Ini

Kebijakan Privasi ini dapat direvisi karena perubahan hukum atau layanan, dan setiap perubahan akan diumumkan di halaman ini. Jika ada perubahan material, kami akan memberi tahu Anda melalui pemberitahuan dalam aplikasi atau catatan pembaruan.

9. Hubungi Kami

Jika Anda memiliki pertanyaan tentang privasi, silakan hubungi kami di bawah ini.
